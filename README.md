<h1>📝 Blogzer - A React Blog Application</h1>
<p>
Blogzer is a fully responsive blog application built using <strong>React.js</strong> for the frontend and <strong>Firebase</strong> for backend services like Authentication, Firestore Database, and Hosting. The design is implemented with <strong>DaisyUI</strong> for a clean and modern UI experience.
</p>

<h2>✅ Features</h2>
<ul>
  <li>User Authentication (Sign Up / Login) via Firebase</li>
  <li>Create, Read, Update, and Delete Blogs</li>
  <li>Responsive and modern UI with DaisyUI</li>
  <li>Real-time data updates using Firebase Firestore</li>
  <li>Secure and fast hosting with Firebase</li>
</ul>

<h2>🛠 Technologies Used</h2>
<ul>
  <li><strong>React.js</strong> (Frontend)</li>
  <li><strong>Firebase</strong> (Authentication, Firestore, Hosting)</li>
  <li><strong>DaisyUI</strong> (Tailwind CSS-based UI Library)</li>
</ul>

<h2>📂 Installation</h2>
<pre>
# Clone the repository
git clone https://github.com/yourusername/blogzer.git

# Navigate to project folder
cd blogzer

# Install dependencies
npm install

# Start development server
npm start
</pre>

<h2>🔐 Firebase Setup</h2>
<ol>
  <li>Create a project in <a href="https://console.firebase.google.com/" target="_blank">Firebase Console</a></li>
  <li>Add your Firebase config in <code>firebase.js</code></li>
  <li>Enable Authentication and Firestore Database</li>
</ol>
